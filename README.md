# Varga Army Run

PWA mobile survival game.

- Sparo automatico
- Nemici centrali: se raggiungono il giocatore, la missione fallisce
- Muri laterali: liberano soldati o super armi
- Mostro supremo al minuto 4:30
- 288 livelli da 5 minuti = 24 ore
- Una nuova ambientazione e disposizione della mappa a ogni missione

Installare una sola volta come PWA. Il service worker aggiorna automaticamente i file al successivo avvio.
